SMART INTERNSHIP MANAGEMENT SYSTEM - FIXED STARTER PROJECT

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Install/enable Live Server if needed.
4. Right-click index.html and choose "Open with Live Server".
5. Login with any username, email, and password of at least 4 characters.
6. Select Student to open dashboard.html, or Supervisor/Admin to open supervisor.html.

IMPORTANT
- This is a front-end prototype, not a production authentication system.
- Login role is stored in sessionStorage for navigation demonstrations only. Real access control requires a backend and server-side authorization.
- Attendance, logbook count, reminders, and form checklist are stored in this browser using localStorage. Files are not uploaded to a server.
- Supervisor performance and student details are sample data.
- Background image is a gradient placeholder. If you have your campus photo, copy it into this folder as campus-bg.jpg; the CSS can then be updated to use it.
